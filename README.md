# BusMap

Fast live bus map + trip planner for Israel. Single static file, no build step.

- Live bus positions (Open Bus Stride / Israeli Ministry of Transport SIRI data)
- Line search, stop departures, A→B trip planner (direct + one transfer)
- Your live location with heading

## Host it free on GitHub Pages
1. Repo → **Settings → Pages**
2. Source: **Deploy from a branch**, branch **main**, folder **/ (root)**
3. Wait ~1 minute, then open `https://<your-username>.github.io/<repo-name>/`

Open it on your phone in Chrome and use **Add to Home screen**.

## Notes
- Needs https for GPS (GitHub Pages provides it).
- Data comes from the volunteer-run Open Bus API, so it can be slow or down at times.
